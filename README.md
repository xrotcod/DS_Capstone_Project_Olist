## Информация о датасете

**Источник**: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Датасет Brazilian ecommerce принадлежит бразильскому крупной платформе-интегратору электронной коммерции "Olist Store". Это реальные коммерческие данные, анонимизированные, названия кампаний были заменены на названия великих домов из сериала "Игра престолов". Датасет содержит информацию о 100 тыс. заказов  за период с 2016 по 2018 год, сделанных на разных бразильских маркетплейсах. 
Olist объединяет малый бизнес со всей Бразилии с каналами без хлопот и с единым контрактом. Эти продавцы могут продавать свою продукцию через магазин Olist и отправлять их непосредственно клиентам, используя партнеров по логистике Olist. После того, как клиент покупает продукт из Olist Store, продавец получает уведомление об исполнении этого заказа. Как только клиент получает продукт или наступает предполагаемая дата доставки, клиент получает опрос удовлетворенности по электронной почте, где он может оценить свой опыт покупки и написать комментарии.
Датасет разделен на 9 частей для лучшего понимания и организации данных. ERD-схема выглядит следующим образом:
![Изображение](https://i.imgur.com/HRhd2Y0.png "ERD-схема")
1. Customers Dataset
Содержит информацию о клиенте и его локации. В датасете кроме customer_id присутствует также unique_customer_id, потому что для каждого заказа у одного и того же клиента будет разное unique_customer_id (это помогает находить клиентов, делающих повторные покупки).
2. Geolocation Dataset
Содержит информацию о бразильских почтовых индексах и координатах широты и долготы локации, городе и штате. Такие данные полезны для построения карт и вычисления расстояния между клиентами и продавцами.
3. Order Items Dataset
Содержит информацию о позициях внутри заказов: вес, размер, цена, продавец, покупатель, крайний срок отправки и стоимость доставки, которая вычисляется по формуле.
4. Payments Dataset
Содержит информацию о подробностях оплаты.
5. Order Reviews Dataset
Содержит информацию об отзывах от клиентов. Клиент оформляет покупку товара в Olist Store, и продавцу приходит уведомление о необходимости выполнить заказ. После получения заказа, и если срок доставки не нарушен, клиенту на почту приходит e-mail c опросом, где он может оценить свой опыт покупки и оставить комментарий.
6. Orders Dataset
Основной датасет, содержит информацию по каждому заказу.
7. Products Dataset
Содержит информацию о продуктах, которые продаются через Olist.
8. Sellers Dataset
Содержит информацию о продавцах, которые выполняют заказы через Olist, и их локации.
9. Category Name Translation
Перевод признака product_category_name  из датасета Products с португальского на английский язык.

## Описание признаков

|Признак|Описание|Значение|
|-|--------|---|
|Customers Dataset|
|**customer_id**|Уникальный идентификатор клиента для каждого заказа (каждый заказ имеет свой id)|Строка (хэш, первичный ключ для связывания с заказами)|
|**customer_unique_id**|Уникальный постоянный идентификатор самого пользователя (позволяет отслеживать повторные покупки)|Строка (хэш)|
|**customer_zip_code_prefix**|Первые 5 цифр почтового индекса покупателя|Числовой / Строка|
|**customer_city**|Город, в котором проживает покупатель|Строка (например, `sao paulo`)|
|**customer_state**|Штат проживания покупателя|Строка (двухбуквенный код, например, `SP`)|
|Geolocation Dataset|
|**geolocation_zip_code_prefix**|Первые 5 цифр почтового индекса местности|Числовой / Строка|
|**geolocation_lat**|Географическая широта точки|Дробное число|
|**geolocation_lng**|Географическая долгота точки|Дробное число|
|**geolocation_city**|Название населенного пункта|Строка|
|**geolocation_state**|Код штата|Строка (двухбуквенный код)|
|Order Items Dataset|
|**order_id**|Идентификатор заказа (внешний ключ к таблице `orders`)|Строка (хэш)|
|**order_item_id**|Порядковый номер товара внутри одного заказа|Целое число (1, 2, 3...)|
|**product_id**|Уникальный идентификатор товара (внешний ключ к `products`)|Строка (хэш)|
|**seller_id**|Уникальный идентификатор продавца (внешний ключ к `sellers`)|Строка (хэш)|
|**shipping_limit_date**|Крайний срок, до которого продавец должен передать товар логистам|Дата и время|
|**price**|Стоимость самого товара (за одну единицу)|Дробное число (BRL)|
|**freight_value**|Стоимость доставки товара (если в заказе несколько позиций, делится между ними)|Дробное число (BRL)|
|Payments Dataset|
|**order_id**|Идентификатор заказа (внешний ключ к таблице `orders`)|Строка (хэш)|
|**payment_sequential**|Порядковый номер транзакции (если заказ оплачивался несколькими способами подряд)|Целое число (1, 2...)|
|**payment_type**|Способ совершения платежа|Строка (`credit_card`, `boleto`, `voucher`, `debit_card`)|
|**payment_installments**|Выбранное количество долей/месяцев рассрочки|Целое число (от 1 до 24)|
|**payment_value**|Общая сумма, списанная по данному платежу|Дробное число (BRL)|
|Order Reviews Dataset|
|**review_id**|Уникальный идентификатор отзыва|Строка (хэш)|
|**order_id**|Идентификатор заказа (внешний ключ к таблице `orders`)|Строка (хэш)|
|**review_score**|Оценка удовлетворенности заказом (от 1 до 5 звезд)|Целое число (1, 2, 3, 4, 5)|
|**review_comment_title**|Заголовок текстового отзыва, оставленного клиентом|Строка (на португальском)|
|**review_comment_message**|Текст самого отзыва|Строка (на португальском)|
|**review_creation_date**|Дата, когда клиенту была отправлена анкета опроса|Дата и время|
|**review_answer_timestamp**|Дата и время, когда клиент фактически заполнил и отправил отзыв|Дата и время|
|Orders Dataset|
|**order_id**|Уникальный идентификатор каждого заказа|Строка (хэш, первичный ключ)|
|**customer_id**|Идентификатор клиента (внешний ключ для связи с таблицей `customers`)|Строка (хэш)|
|**order_status**|Текущий статус выполнения заказа|Строка (`delivered`, `shipped`, `canceled`, `invoiced` и др.)|
|**order_purchase_timestamp**|Дата и время совершения покупки клиентом|Дата и время (YYYY-MM-DD HH:MM:SS)|
|**order_approved_at**|Дата и время подтверждения/оплаты платежа|Дата и время|
|**order_delivered_carrier_date**|Дата и время передачи заказа логистической компании|Дата и время|
|**order_delivered_customer_date**|Фактическая дата и время доставки заказа покупателю|Дата и время|
|**order_estimated_delivery_date**|Планируемая (обещанная) дата доставки, отображаемая клиенту|Дата|
|Products Dataset|
|**product_id**|Уникальный идентификатор продукта|Строка (хэш, первичный ключ)|
|**product_category_name**|Категория товара на португальском языке|Строка (например, `beleza_saude`)|
|**product_name_lenght**|Длина наименования товара в символах|Целое число|
|**product_description_lenght**|Длина текста описания товара в символах|Целое число|
|**product_photos_qty**|Количество опубликованных фотографий к товару|Целое число|
|**product_weight_g**|Вес товара в граммах|Целое число|
|**product_length_cm**|Длина товара в сантиметрах|Целое число|
|**product_height_cm**|Высота товара в сантиметрах|Целое число|
|**product_width_cm**|Ширина товара в сантиметрах|Целое число|
|Sellers Dataset|
|**seller_id**|Уникальный идентификатор продавца|Строка (хэш, первичный ключ)|
|**seller_zip_code_prefix**|Первые 5 цифр почтового индекса продавца|Числовой / Строка|
|**seller_city**|Город регистрация продавца|Строка|
|**seller_state**|Штат регистрация продавца|Строка (двухбуквенный код)|
|Category Name Translation|
|**product_category_name**|Категория товара на португальском языке (для связи с таблицей `products`)|Строка (например, `beleza_saude`)|Текст|
|**product_category_name_english**|Перевод названия категории на английский язык|Строка (например, `health_beauty`)|Текст|
